# K. Lohith | Personal Portfolio 🌐

A single-page personal portfolio website: about me, education, technical skills and a working contact form.

## ✨ Features
- Tabbed sections: **About**, **Skills**, **Contact**
- Contact form that sends messages straight to my inbox using [EmailJS](https://www.emailjs.com/), with no backend needed
- Responsive layout that works on phones and laptops
- Pure **HTML + CSS + JavaScript** in one `index.html` file

## 🚀 View it
Open `index.html` in any browser, or host it for free with **GitHub Pages**: *Settings → Pages → Deploy from branch → `main`*.
